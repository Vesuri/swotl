# External surface (SWOTL 2.2, in scope)

Every interrupt, port and VGA access of the in-scope modules. Generated by
`tools/surface.py` (`make map`) from the sweep and the trace corpus
(94 traces: milestones m0–m7 and coverage scripts c1–c85); counts are summed
over the corpus. The tool fails if a traced guest site is not a decoded static
instruction.

Owners: root `+04442..+04997` = the game's device layer (mouse, joystick,
EMS, video probe, vectors); root `+13692..+1615B` = MS C runtime
(`annotations/runtime.csv`); root `+16170..` = PLINK ([plink.md](plink.md));
RTSVGA = graphics driver; SPAZ = AdLib music/effects and timer.
